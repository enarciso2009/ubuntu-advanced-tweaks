# Ubuntu Advanced Tweaks

Um utilitário nativo desenvolvido em **Linguagem C** e **GTK 3** feito sob medida para usuários iniciantes no Linux. Ative funções avançadas e ocultas do Ubuntu com apenas um clique, sem precisar abrir o terminal ou decorar comandos complexos de `gsettings`!

##  Funcionalidades
* **Janelas:** Centralizar novas janelas automaticamente na tela.
* **Barra Superior:** Exibir a porcentagem da bateria.
* **Performance:** Modo Desempenho (desativa as animações do sistema).
* **Dock:** Forçar a Dock a ficar 100% transparente.
* **Dock:** Ativar clique no ícone para minimizar o aplicativo.

---

## Como Baixar e Executar (Sem Compilar nada!)

Para facilitar a vida de quem não quer abrir o terminal para programar, o aplicativo já está compilado e pronto para uso!

1. Vá na seção **Releases** no menu lateral direito desta página.
2. Baixe o arquivo executável `ubuntu-tweaks`.
3. Abra o seu terminal apenas uma vez na pasta onde baixou o arquivo e dê permissão de execução com o comando:
   ```bash
   chmod +x ubuntu-tweaks
   ```
4. Pronto! Agora basta dar **dois cliques** no arquivo `ubuntu-tweaks` pelo seu gerenciador de arquivos e a interface vai se abrir na sua tela!

*Nota: Caso o programa não abra, certifique-se de ter as bibliotecas visuais do sistema atualizadas rodando `sudo apt install libgtk-3-dev -y` no terminal.*
